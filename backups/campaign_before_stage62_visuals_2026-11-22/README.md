# 1~5스테이지 공 표시 적용 전 백업

2026-11-22 현재 작업 트리의 파일을 변경 전에 바이트 단위로 복사하고 SHA-256 일치를 확인했다. `.bak` 확장자는 Godot이 같은 UID의 레벨을 중복 등록하지 않게 하기 위함이다.

- `resources/levels/`의 5개 `.tres.bak`: 원래 1~5스테이지 설정.
- `scripts/`의 3개 `.gd.bak`: 적용 전 연결 코드 참고본.
- 공 표시만 원복하려면 각 `.tres.bak`를 원래 `resources/levels/` 경로에 `.bak` 없이 복사한다. 선택적 표시 씬이 연결되지 않으므로 추가 시각화는 실행되지 않는다. 스크립트 참고본은 이후 변경을 덮어쓸 수 있어 자동 복원하지 않는다.

적·캐릭터·이미지 등 참조 파일 전체를 동결한 프로젝트 백업은 아니다. 이번 작업은 그 원본들을 변경하지 않는다.
