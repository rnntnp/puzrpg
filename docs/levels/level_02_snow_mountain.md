# 레벨 2 · 추운 설산

팀 공유용 현재 런타임 기준 문서다. 수치와 행동은 `resources/levels/level_02.tres` 및 연결된 Character/Skill Resource를 기준으로 한다.

## 레벨 콘셉트

`빙결 지대`를 중심으로, 몬스터의 직접 피해보다 보드의 합성 가능한 공을 얼려 선택지를 줄이는 것이 핵심 압박이다. 빙결된 공은 고정되어 합성할 수 없으며, 일반 합성으로 얼음 내구도를 깎아 해제한다.

## 몬스터 구성

| 순서 | 몬스터 | HP | 일반 공격 | 스킬 대기 | 공격 대기 | 빙결 수 | 우선 단계 | 얼음 내구도 |
|---:|---|---:|---:|---:|---:|---:|---|---:|
| 1 | 설원 설인 | 600 | 4 | 3턴 | 2턴 | 1개 | 1~3단계 | 2 |
| 2 | 설산 강화 몬스터 | 800 | 5 | 3턴 | 2턴 | 2개 | 2~4단계 | 2 |
| 3 | 설원 설인 대장 | 900 | 6 | 4턴 | 2턴 | 3개 | 3~5단계 중심 + 주변 | 3 |

`턴`은 버튼을 누른 횟수가 아니라, 공이 착지하고 합성 정산이 끝난 뒤 발생하는 `turn_completed` 기준이다. 적 전환 시 보드와 이미 완료된 빙결은 모두 유지된다.

## 빙결 행동 순서

1단계와 3단계 몬스터는 빙결 스킬로 시작하고, 2단계 강화 몬스터만 2턴 뒤 일반 공격으로 시작해 공이 더 쌓인 다음 첫 2개 빙결을 사용한다. 이후에는 모두 빙결 스킬과 일반 공격을 교대로 반복한다. 빙결 행동에는 직접 피해가 없고, 일반 공격 턴에만 낮은 피해를 준다. 스킬 후에는 2턴 뒤 일반 공격하며, 일반 공격 후 다음 스킬까지는 몬스터별로 3/3/4턴을 기다린다. 따라서 안정화 이후 빙결 스킬의 반복 간격은 각각 5/5/6턴이다. 평상시 입력은 유지되며, 빙결 행동 예정 턴에는 공을 투하하는 즉시 입력을 잠가 첫 착지 후에도 다음 공을 투하할 수 없게 한다. 마지막 합성 후 0.5초가 지나면 대상 조준 → 얼음 투사체 → 빙결 순서로 행동하며, 모든 빙결 연출이 끝난 뒤 입력을 다시 연다. 일반 공격은 보드를 변경하지 않으므로 별도의 장시간 입력 잠금을 사용하지 않는다.

## 대상 탐색 규칙

각 몬스터는 우선 시작 단계 이상을 모두 처리한 뒤에만 낮은 단계로 내려간다.

- 설산 강화 몬스터: `2 → 3 → 4 → … → 11`, 마지막 보충 단계에서 `1`
- 설원 설인: `1 → 2 → 3 → 4 → … → 11`
- 설원 설인 대장: `3 → 4 → 5 → … → 11`, 마지막 보충 단계에서 `2 → 1`

설원 설인은 위 단계 순서로 얼지 않은 공 후보를 최대 6개까지 모은 뒤 후보를 섞어 1개를 무작위로 선택한다. 얼지 않은 후보가 없을 때만 기존 재빙결 우선순위를 사용한다.

설산 강화 몬스터는 위 단계 순서로 얼지 않은 공 후보를 최대 6개까지 모은 뒤 후보를 섞어 2개를 무작위로 선택한다. 얼지 않은 후보가 2개보다 적을 때만 기존 재빙결·저단계 우선순위로 부족한 수를 보충한다.

설원 설인 대장은 기존 단계 우선순위로 얼지 않은 공 후보를 최대 6개까지 모은 뒤, 그중 하나를 무작위로 중심 대상으로 고른다. 얼지 않은 후보가 전혀 없을 때만 기존 재빙결 우선순위의 첫 공을 중심으로 사용한다. 그다음 단계와 관계없이 중심 대상과 거리가 가장 가까운 얼지 않은 공 2개를 추가해 총 3개를 빙결한다. 주변의 얼지 않은 공이 부족하면 기존 우선순위 탐색 결과로 남은 수를 보충한다.

요청된 빙결 수가 2개라면 우선 시작 단계부터 11단계까지의 얼지 않은 공을 탐색한다. 부족하면 같은 단계 범위의 손상된 얼음을 재빙결하고, 그래도 부족하면 같은 범위의 최대 내구도 얼음을 강화한다. 이 세 검색을 모두 마친 뒤에도 부족할 때만 시작 단계 바로 아래부터 1단계까지 같은 `일반 공 → 손상된 얼음 → 최대 내구도 얼음` 순서로 보충한다. 최대 빙결 슬롯 제한은 없다.

빙결 표시가 있는 공 하나가 합성되면 합성 결과 공이 표시를 상속하며, 이후 연쇄 합성에서도 같은 계보를 따라간다. 빙결 표시가 있는 공 두 개가 서로 합성되면 결과 공에는 표시 하나를 유지하고, 합쳐진 두 번째 슬롯은 현재 보드에서 새 대상을 탐색해 예고한다. 합성이 아닌 이유로 표시 대상이 사라진 경우에는 실행 시점에 해당 슬롯을 재탐색한다.

빙결 실행 시점에 표시 공의 합성이 이미 확정되어 `merge_locked` 상태라면 그 원본을 건너뛰지 않고 합성 결과를 최대 0.5초 추가로 기다린다. 결과 공이 생성되면 표식을 이전하고 즉시 빙결 시전 예약 상태로 만들어 추가 합성을 막은 뒤 반드시 빙결한다. 실행 시점에 아직 합성이 확정되지 않은 표시 공도 바로 시전 예약하여 같은 프레임 이후의 새 합성을 차단한다. 결과 생성 실패나 대상 소실 시에는 부족 슬롯을 새 대상으로 채우며, 실제 빙결 완료 또는 확정 실패 전에는 대상 추적을 비우지 않는다.

적이 죽으면 아직 투사체를 발사하지 않은 예고, 합성 결과 대기, 시전 예약 대상은 모두 취소한다. 이미 발사되어 비행 중인 투사체는 적 사망과 관계없이 목표에 도착해 빙결을 적용한다. 완료된 얼음과 이 마지막 투사체가 만든 얼음은 다음 적에게도 유지된다. 지연된 이전 합성 결과는 원본 ID가 현재 대상 목록에 있을 때만 표식을 승계하므로, 취소된 이전 적의 표식이 다음 적에게 넘어가지 않는다. 적 교체 중 발사 요청 시점에 도착한 플레이어 합성 공격은 다음 적 등장 후 정상 투사체로 발사되지만 합성 완료 이벤트를 다시 내보내지 않으므로, 해당 합성으로 얼음 내구도가 중복 감소하지 않는다.

얼어 있는 공을 재빙결하면 손상 여부와 관계없이 동일한 빙결 연출을 재생하고 현재 내구도에 해당 몬스터의 기본 부여 내구도를 더한다. 예를 들어 내구도 2를 부여하는 몬스터는 `1 → 3`, `2 → 4`로 강화하고, 보스는 `1 → 4`, `2 → 5`, `3 → 6`으로 강화한다. 현재는 모든 몬스터의 빙결 행동에서 직접 공격을 분리했으므로, 최종적으로 목표 개수를 채우지 못해도 대상 부족 추가 피해는 발생하지 않는다.

## 얼음 내구도와 시각 피드백

- 일반 합성이 완료될 때마다 보드의 모든 얼음 내구도가 1 감소한다.
- 내구도가 0이 되면 얼음이 해제되고 공은 다시 움직이며 합성할 수 있다.
- 현재 얼음 본체는 내구도와 관계없이 같은 청백색 셰이더를 사용한다.
- 내구도 숫자 라벨도 현재 3/2/1 모두 같은 노란색을 사용한다.
- 따라서 현재 런타임에서는 숫자 외에 내구도별 색상 구분이 적용되어 있지 않다.

## 구현 위치

- 레벨 등록/적 순서: `resources/levels/level_02.tres`
- 적 수치: `resources/characters/ice_monster.tres`, `ice_monster_enhanced.tres`, `ice_monster_boss.tres`
- 빙결 수치: `resources/skills/basic_ice.tres`, `enhanced_ice.tres`, `boss_ice.tres`
- 대상 탐색/빙결 연출: `scripts/ice_skill_controller.gd`
- 얼음 상태/내구도/시각 표시: `scripts/merge_ball.gd`
- 적 턴 카운트와 행동 연결: `scripts/monster_action_controller.gd`

## 팀 플레이테스트 확인 항목

1. 시작 단계 이상에서 일반 공, 손상된 얼음, 최대 내구도 얼음을 모두 검색한 뒤에만 낮은 단계로 내려가는가?
2. 일반 공이 부족하면 손상된 얼음, 최대 내구도 얼음 순으로 남은 대상을 채우는가?
3. 최대 내구도 얼음을 다시 대상으로 삼았을 때 빙결 연출과 내구도 누적이 정상 적용되는가?
4. 빙결 행동 예정 턴의 투하 직후부터 모든 빙결 연출 종료까지 입력이 유지해서 잠기는가?
5. 적 전환 후 기존 얼음은 유지되고, 미발사 표식은 사라지며, 이미 날아간 투사체만 정상적으로 빙결을 완료하는가?
6. 설인 대장이 기존 우선순위로 중심 공을 고르고, 실제 거리상 가장 가까운 얼지 않은 공 2개를 함께 얼리는가?
