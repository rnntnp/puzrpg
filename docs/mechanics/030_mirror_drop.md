# 030 미러 드롭 보스

## 규칙

- 이 테스트 레벨은 단일 보스전이며 `NORMAL 3회 → MIRROR 3회`를 반복한다. 횟수는 플레이어의 완료된 투하 기준이며 보스 미러 공은 턴을 소비하지 않는다.
- Normal Phase에는 일반 투하·합성·콤보·보스 피해가 그대로 적용된다. 세 번째 투하의 물리와 연쇄가 정리된 뒤 별도 공격 피해 없이 Mirror Phase에 진입한다.
- Mirror Phase에는 플레이어가 실제로 적용한 투하 X와 표시 단계를 기록하고 즉시 입력을 잠근다. 플레이어 투하의 물리와 연쇄가 정리된 뒤, 실제 드롭 가능 범위의 중앙을 기준으로 반사한 X에서 같은 단계의 보스 공을 생성한다.
- Mirror Phase에는 플레이어가 공을 놓는 즉시 입력을 잠근다. 첫 착지가 다음 공 입력을 다시 열지 못하게 하며, 해당 보스 응수가 끝난 뒤에만 입력을 반환하여 `플레이어 1회 → 보스 1회` 교대를 보장한다.
- 보스 공은 Next Queue를 소비하거나 변경하지 않고 플레이어 턴을 추가하지 않는다. 검은 위험 표식은 응수가 끝나도 유지되며 해당 공이 합성될 때 한 번 소모된다.
- 플레이어 투하가 만든 합성은 보스 응수 중 늦게 완료되더라도 기존 점수·콤보·보스 피해를 유지한다. 검은 미러 공이 직접 참여한 합성만 별도 Boss Combo로 계산하고 플레이어에게 피해를 준다. 합성 결과 공은 검은 표식과 보스 소유권을 이어받지 않는 정상 공이다.
- Boss Combo는 점수, 플레이어 콤보, 보스행 합성 투사체를 만들지 않는다. 각 합성의 기존 단계 점수와 `min(2.0, 1 + 0.25 × (Boss Combo 순번 - 1))` 배율로 정상 피해를 계산한 뒤 0.20배 피해의 투사체를 합체 지점에서 플레이어에게 발사한다. 투사체 충돌 순간 피해가 적용된다.
- 세 번째 미러 응수와 그 연쇄까지 정리한 뒤 Normal Phase로 돌아간다. 모든 공과 보드 상태는 유지한다.

## 플레이어 정보와 대응

- 보스 기본 크기는 기존 대비 0.8배다. Normal Phase에는 청록 은색 프레임, 짙은 회색 거울면, 흰색 표정선을 가진 전용 idle을 사용한다. Mirror Phase 진입 시 반사 캐릭터가 보이는 스프라이트로 교체하고, 짧은 반사 섬광음을 한 번 재생하며, 거울면 안쪽에만 사선 광택이 반복 이동한다.
- Normal Phase에는 `MIRROR PHASE · N`으로 준비 시간을 표시한다.
- Mirror Phase에는 단계 숫자를 표시하지 않는다. 반사 위치에는 실제 공 크기와 형태를 사용하며 구슬 배경만 완전 불투명 검정으로 표시한다. 광택과 내부 우파루파는 원래 색을 유지하고 별도의 반투명 페이드는 사용하지 않는다. 단, 1단계는 내부 우파루파가 검은 배경을 대부분 가리므로 내부 스프라이트도 검게 표시한다.
- 미러 공의 검은 위험 표식은 구슬 배경을 검게 채운다. 1단계는 내부 우파루파가 배경을 대부분 가리므로 위험 표식 동안 내부 스프라이트도 검게 표시하고, 표식이 소모되면 원래 색으로 복원한다.
- 미러 공의 첫 착지음과 미러 공이 참여한 합성음은 플레이어 공과 같은 원본 효과음을 사용하되 훨씬 낮은 피치로 재생한다. 미러 합성 버스트는 기존보다 크게 표시하고 짙은 검정·남색 계열로 구분하며, 합성 후 플레이어에게 날아가는 굵은 공격 궤적과 투사체는 공 단계 색 대신 검정으로 표시한다.
- 보드 중앙에는 Mirror Phase 동안만 낮은 명도의 점선을 표시한다. 플레이어 조준점과 반대 방향으로 움직이는 원을 함께 보여 대칭축과 응수 위치를 전달한다.
- 보드 내부의 `BOSS MIRROR DROP`, 단계 숫자, Boss Combo 결과 패널은 표시하지 않는다. 상세 규칙은 스테이지 안내와 보드 밖 기믹 UI가 담당한다.
- 의도된 좋은 수는 플레이어 투하 위치에는 같은 단계 공을 준비하고, 반사 위치에는 같은 단계 공을 두지 않는 것이다.

## 기존 시스템 관계

- 보스 미러 공은 정상 `MergeBall`이며 착지 후 합성, 물리, Danger Line에 모두 참여한다.
- Boss Combo의 공격 연출은 기존 합체 투사체를 반대 방향으로 재사용한다.
- 보스 응수 중 입력이 잠겨 있는 동안 기존 Danger Line 타이머가 일시 정지되며, 응수 종료 후 실제 오버플로를 정상 재평가한다.
- 보스 응수는 별도 플레이어 투하 시퀀스를 시작하지 않는다. 전용 외부 합성 구간에서만 독립 Boss Combo를 사용한다.
- 응수마다 새로운 소유권 토큰을 사용한다. 외부 합성 구간이 끝난 뒤에는 공 자체의 검은 위험 표식이 피해 소유권을 유지하며, 기존 정상 공끼리의 합성은 Boss Combo로 오인하지 않는다.
- Skill Gauge와 공통 Break 시스템은 현재 런타임에 없으므로 적용하지 않는다.
- 적 사망, 플레이어 사망, 재시작 또는 장면 종료 시 예약 행동과 외부 합성 구간 및 전용 시각화를 정리한다.

## 초기 튜닝 및 플레이테스트

- 보스 HP 1000, Normal 3회, Mirror 3회, Normal Phase 종료 공격 없음, Mirror Damage Scale 0.20. 착지 피치 0.55, 합성 기본 피치 0.62, 미러 합성 이펙트 크기 1.35배.
- 일반 페이즈의 1·2번째 투하는 기믹 자체의 추가 입력 잠금이나 전체 보드 안정화 대기를 사용하지 않는다.
- 보스 행동은 미러 생성 전 0.20초 예고를 둔다. 미러 공은 시간 제한으로 공중 낙하 도중 턴을 반환하지 않으며 실제 첫 접촉을 반드시 기다린다. 첫 접촉부터 0.50초 동안 합성을 관찰하고, Boss Combo가 발생할 때마다 마지막 합성 시점부터 0.50초를 다시 계산한 뒤 정산을 끝낸다.
- 보스 행동 종료 후 0.10초 뒤 플레이어 입력을 돌려준다. 다른 공이 계속 움직이더라도 전체 보드 정지를 요구하지 않는다.
- 확인: Normal Phase가 실제 좌우 비대칭 준비 시간인지, Ghost로 두 결과를 읽을 수 있는지, 0.20배 피해가 한두 번의 실수는 허용하는지, 보스가 남긴 공을 다음 Normal Phase에서 자원으로 활용하는지, 세 번의 응수가 늘어지지 않는지.
