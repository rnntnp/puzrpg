## 핵심 규칙

보드는 LEFT, CENTER, RIGHT 세 구역으로 나뉜다. UI가 현재 주문의 구역과 필요하면 결과 공 단계를 표시한다. 정상 합성의 중심점이 주문 구역 안에 있고 결과 단계 조건을 만족하면 주문이 진행 또는 완성된다.

- 판정은 `정상 합성 등록 시점`의 결과 단계와 합성 중심 위치를 사용한다.
- 구역 경계의 점은 X 좌표 계산 결과가 속한 단일 구역에서만 판정한다.
- 조건이 맞지 않는 합성은 정상 점수, 피해, 콤보를 그대로 발생시키지만 주문은 진행하지 않는다.
- 주문 제한 턴이 0이 되면 실패 공격을 받고 다음 주문으로 교체된다.
- 주문 성공 보너스 피해는 정상 합성 피해와 별도로 적에게 적용된다.

## Enemy 1 — Teach: 구역 주문

- 하나의 구역만 표시한다.
- 결과 단계는 `ANY`다.
- 제한 턴 안에 표시 구역에서 정상 합성을 한 번 만들면 즉시 주문 성공이다.
- 예상 플레이: LEFT 주문을 본 플레이어가 같은 단계 공이 모인 왼쪽으로 현재 공을 투하한다. 합성 중심이 LEFT에 생기고 주문 보너스 피해가 발생한다.

## Enemy 2 — Twist: 구역 + 단계 주문

- 구역과 결과 단계를 함께 표시한다.
- 요청 단계는 현재 보드, 현재 공, 다음 공에서 확인되는 합성 가능 쌍을 기준으로 선택한다.
- 확인 가능한 쌍이 없으면 해당 주문만 단계 조건을 `ANY`로 완화한다. 숨겨진 미래 큐를 근거로 불가능한 주문을 만들지 않는다.
- 예상 플레이: RIGHT · STAGE 3 주문을 본 플레이어가 오른쪽의 2단계 공 근처로 현재 2단계 공을 투하한다. 다른 구역의 3단계 합성은 정상 피해만 주고 주문은 남는다.

## Boss — Mastery: 2단계 연속 주문

- 하나의 제한 턴을 공유하는 두 단계 주문을 순서대로 수행한다.
- 각 단계는 구역과 결과 단계를 요구한다. 확인 가능한 단계 쌍이 없으면 그 단계만 `ANY`다.
- 첫 주문 성공 후 생성된 결과 공까지 보드 상태에 포함한 다음 두 번째 주문을 결정한다.
- 다른 합성은 진행도를 초기화하지 않지만 제한 턴은 계속 감소한다.
- 두 단계를 모두 완료해야 보너스 피해가 발생하고 새 연속 주문이 시작된다.
- 예상 플레이: `1/2 LEFT · STAGE 2`를 먼저 완성한 뒤 새로 표시된 `2/2 CENTER · STAGE 3`을 위해 결과 공과 중앙의 같은 단계 공을 연결한다.

## 타이밍과 판정

- 주문은 각 적 등장 시 즉시 표시된다.
- 제한 턴은 완료된 플레이어 투하 단위로 감소한다.
- 주문을 성공시킨 합성이 포함된 투하는 새 주문의 제한 턴을 즉시 감소시키지 않는다.
- 실패 판정이 난 투하에서는 실패 공격 후 새 주문을 표시하지만 같은 투하로 새 주문의 턴을 추가 감소시키지 않는다.
- Boss 첫 단계만 성공한 경우 같은 연속 주문의 제한 턴이 계속 흐른다.
- 성공 보너스로 적이 사망하면 새 주문을 만들지 않고 기존 적 전환 흐름을 따른다.

## 기존 시스템과의 관계

- 정상 합성, 연쇄 합성, 점수, 기본 피해, 콤보는 변경하지 않는다.
- 한 투하에서 발생한 여러 정상 합성은 발생 순서대로 각각 주문과 비교한다.
- 기믹이 공이나 지형을 생성하거나 움직이지 않으므로 재귀 합성 입력은 만들지 않는다.
- Skill Gauge와 공용 Break 시스템은 현재 런타임에 없으므로 적용하지 않는다.
- Danger Line 규칙과 물리 속성은 변경하지 않는다.
- Enemy 1 → Enemy 2 → Boss 전환 시 공 보드는 유지하고, 미완료 주문과 제한 턴은 새 적 규칙으로 초기화한다.

## 주요 예외

- 주문 구역에 공이 없어도 주문은 유지된다. 플레이어는 이후 투하로 합성을 만들 수 있다.
- 정확 단계 후보가 없으면 `ANY`를 표시하며 내부적으로 임의 단계를 추측하지 않는다.
- 동시에 요청을 만족하는 합성이 여러 번 발생해도 이미 새 주문으로 넘어간 뒤의 합성은 새 주문과 다시 비교한다.
- 적 사망, 레벨 종료, 재시작 시 구역 표시, 진행도, 최근 합성 피드백과 대기 판정을 모두 제거한다.

- 보드 3분할 경계선

- `ANY` 또는 `STAGE N` 결과 단계
- 최근 합성 위치의 성공/실패 원형 표시
- 성공, 실패, 조건 불일치 텍스트
