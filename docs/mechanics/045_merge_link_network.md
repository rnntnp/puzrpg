## 핵심 규칙과 판정 시점

- 정상 합성 하나가 등록될 때마다 합성 원점에 임시 연결 노드 하나가 생긴다.
- 노드끼리는 중심 거리가 연결 거리 이내일 때 이어진다. 비콘과 노드는 별도의 비콘 도달 거리 이내일 때 이어진다.
- 비콘끼리는 직접 연결되지 않는다. 성공하려면 최소 한 개 이상의 합성 노드가 필요하다.
- 각 노드는 배치된 턴을 포함해 표시된 수명 동안 유지되며, 성공하지 못한 논리 턴이 끝날 때 수명이 1 감소한다.
- 매 논리 턴 완료 시 현재 연결망을 먼저 판정한다. 요구 비콘이 한 연결 성분에 들어오면 즉시 성공한다.
- 계약 제한 턴이 0이 될 때까지 연결하지 못하면 실패한다.
- 성공 시 적에게 보너스 피해, 실패 시 플레이어에게 기믹 공격 피해를 준다. 결과 표시 뒤 모든 노드를 지우고 다음 계약을 시작한다.

## 3연전

### Enemy 1 — Teach: 비콘 충전

- LEFT, RIGHT, CENTER 중 비콘 하나만 활성화한다.
- 제한 턴 안에 비콘 도달 범위 안에서 정상 합성을 한 번 만들면 성공한다.
- 예상 플레이: 표시 비콘 쪽의 같은 단계 공을 향해 현재 공을 떨어뜨려 합성 노드가 비콘 원과 겹치게 한다.

### Enemy 2 — Twist: 좌우 브리지

- 같은 높이의 LEFT와 RIGHT 비콘을 동시에 표시한다.
- 여러 합성 노드의 범위를 이어 두 비콘 사이에 하나의 경로를 만들어야 한다.
- 예상 플레이: 먼저 왼쪽 근처에 노드를 만든 뒤 중앙과 오른쪽으로 합성 위치를 확장한다. 오래된 노드가 사라지기 전에 마지막 연결을 완성한다.

### Boss — Mastery: 분기형 연결망

- 위쪽 좌우 비콘과 아래쪽 중앙 허브를 표시한다.
- LEFT, CENTER, RIGHT 세 비콘이 모두 같은 연결망에 포함되어야 한다.
- 예상 플레이: 중앙 허브에서 좌우로 갈라지는 두 합성 경로를 준비하고, 수명이 짧은 쪽을 갱신하거나 마지막 합성으로 두 갈래를 동시에 완성한다.

## 공통 시스템 관계와 예외

- 정상 합성, 연쇄 합성, 결과 공, 점수, 합성 피해와 콤보는 변경하지 않는다.
- 연쇄 합성의 각 정상 합성은 각각 노드 하나를 만든다.
- 기믹은 공을 생성·삭제·이동시키거나 물리 속성을 바꾸지 않는다.
- Skill Gauge와 공용 Break는 현재 런타임에 없으므로 적용하지 않는다.
- Danger Line 규칙과 판정은 변경하지 않는다.
- 같은 위치에 여러 노드가 겹쳐도 각각 수명을 가진다. 최대 표시 개수를 넘으면 가장 오래된 노드부터 제거한다.
- 마지막 낙하의 합성 노드는 수명 감소 전 연결 판정에 사용된다.
- 합성 피해로 적이 먼저 사망하면 아직 판정되지 않은 계약은 성공·실패 효과를 발생시키지 않는다.
- 성공 보너스로 적이 사망하면 새 계약을 만들지 않는다. 실패 피해로 플레이어가 사망해도 같다.
- 적 전환 시 보드는 유지하지만 노드, 비콘 배치, 계약 진행과 결과 표시는 초기화한다.
- 재시작·레벨 종료 시 모든 연결 노드와 표시를 제거한다.

## 표시와 플레이테스트 확인점

- 비콘 위치와 도달 범위, 노드 위치·수명·연결 범위, 현재 연결선을 표시한다.
- 연결된 비콘은 초록색, 아직 고립된 비콘은 주황색으로 구분한다.
- 남은 계약 턴과 성공·실패 결과를 표시한다.
- 확인할 점: 노드가 생긴 합성 위치와 연결 이유가 즉시 이해되는지, Twist를 2~3개 노드로 계획할 수 있는지, Boss의 V자 분기가 X 조작과 적층 높이 선택으로 조절 가능하게 느껴지는지, 수명과 제한 턴이 과도하게 빡빡하지 않은지.
