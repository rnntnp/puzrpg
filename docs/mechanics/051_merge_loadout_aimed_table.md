# 051 · 능력 편성 / 하단 방향 발사

Status: `NEEDS_PLAYTEST`

## Core contract

- 메인 메뉴에서 1~10단계 우파루파에 강타, 수호, 집중, 쇠약을 자유롭게 장착·해제·이동한다.
- 같은 단계 두 공이 합쳐질 때 결과 단계가 아니라 두 원본 공의 단계에 장착된 능력이 한 번 발동한다.
- 기본 합성, 점수, 콤보, 스킬 게이지와 합성 공격은 유지된다.
- 공은 화면 아래 중앙에서 발사한다. 플레이어는 위쪽을 향하는 방향만 지정하며 드래그 길이는 힘에 영향을 주지 않는다.
- Merge Zoo의 체감을 참고해 발사 힘보다 위쪽 역중력이 이동을 주도한다. 공은 비교적 약하게 출발하고 위로 가속되어 천장 아래에 쌓인다.
- 좌우 조준은 약한 발사에서도 보드 폭을 사용할 수 있도록 수평 운동량만 별도로 보강한다.
- 공과 벽의 반발은 낮고 감쇠는 기본 수박게임보다 높아, 천장이나 다른 공에 닿은 뒤 짧게 흔들리고 정착한다.
- 발사구와 플레이 영역 사이의 선은 충돌 칸막이가 아니라 쌓임 한계를 읽기 위한 표시로 사용한다.
- 합성 충격은 주변 배치를 흔들되 공 무리를 멀리 날리지 않는 수준으로 낮춘다.
- 아래 발사구와 위 플레이 영역은 단방향 칸막이로 구분한다. 발사 공은 위로 통과하지만 플레이 중인 공은 발사구로 내려오지 않는다.
- 중력이 반대이므로 기존 상단 위험선은 이 테스트에서 사용하지 않는다.
- 기존 적 2종과 보스를 순서대로 사용하며, 각 적은 정해진 완료 턴마다 공격한다.

## Ability rules

- 강타: 해당 합성 공격을 강화한다.
- 수호: 다음 적 공격에서 피해를 막으며, 그 공격 후 잔여 보호막도 사라진다.
- 집중: 이후 합성 공격을 강화하는 충전을 최대 2개 저장한다.
- 쇠약: 다음 적 공격을 약화한다. 중복 시 합산하지 않고 가장 강한 값만 유지한다.
- 보호막, 집중, 쇠약은 적 교체 시 초기화한다. 공 배치와 편성은 유지한다.

## Prototype questions

- 52번과 비교했을 때 아래에서 위로 쏘는 방향이 보드 판단을 어떻게 바꾸는가?
- 벽 반사가 예상 가능하면서도 물리 조작이 능력 편성을 압도하지 않는가?
- 조준·파워 판단과 능력 편성 판단이 서로 경쟁하지 않고 연결되는가?
- 한 발 이후 다음 턴까지의 대기 시간이 답답하지 않은가?
