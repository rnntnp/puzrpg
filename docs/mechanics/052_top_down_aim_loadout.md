# 052 · 능력 편성 / 상단 방향 발사

Status: `NEEDS_PLAYTEST`

## Core contract

- 51번과 동일한 단계별 능력 편성을 사용한다.
- 공은 화면 위 중앙의 고정된 발사구에서 시작한다.
- 플레이어는 아래쪽을 향하는 발사 방향만 지정한다. 드래그 길이는 발사 힘에 영향을 주지 않는다.
- 모든 공은 동일한 고정 세기로 출발한다. 중력 때문에 조준 방향이 지나치게 수직으로 꺾이지 않도록 수평 운동량을 보강한다.
- 좌우 벽은 이 레벨에서만 중간 정도의 반발력을 갖는다. 직접 발사 운동량은 낮게 유지하고, 벽을 한 번 이용해 안쪽으로 꺾어 넣는 배치를 허용한다.
- 같은 단계 합성, 능력 발동, 기본 공격, 점수, 콤보, 스킬 게이지와 위험선은 유지한다.
- 합성 결과의 속도 계승과 합성 충격을 포함한 나머지 물리는 기존 수박게임 규칙을 그대로 사용한다.
- 기존 적 2종과 보스를 사용하고 공 배치는 적 사이에 유지한다.
