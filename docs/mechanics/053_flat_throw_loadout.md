# 053 · 능력 편성 / 평면 던지기

Status: `NEEDS_PLAYTEST`

## Core contract

- 51·52번과 동일한 단계별 능력 편성을 사용한다.
- 아래 발사구에서 드래그 방향과 길이로 공의 방향과 초기 세기를 정한다.
- 플레이 영역에는 중력이 없다. 발사된 공은 평평한 바닥을 미끄러지며 매 순간 일정량의 속도를 잃는다.
- 낮은 속도에서는 즉시 정지해 장시간 천천히 움직이는 구간을 제거한다.
- 공끼리 충돌하면 양쪽 모두 운동량을 크게 잃는다. 벽에서는 진행 속도를 일부 유지해 약하게 반사되거나 벽을 따라 조금 이동한 뒤 감속한다.
- 다음 발사는 보드의 미세한 잔류 움직임을 무시하며, 턴 정리 대기는 최대 1.8초로 제한한다.
- 합성 결과는 원본 속도의 일부만 계승하며 합성 충격은 주변 공을 조금 움직이는 수준으로 제한한다.
- 발사 공은 단방향 경계를 지나 플레이 영역에 들어가며, 기존 공은 발사구로 돌아오지 않는다.
- 기존 적 2종과 보스를 사용하고 공 배치와 편성을 적 사이에 유지한다.

## Prototype questions

- 약한 던지기와 강한 던지기를 모두 의도적으로 사용하는가?
- 발사 결과가 빠르게 끝나면서도 목표 위치 선택은 충분히 남아 있는가?
- 충돌로 기존 배치를 약간 수정하는 재미가 알까기처럼 과해지지 않는가?
- 51번 역중력과 52번 중력 방식보다 능력 편성·턴제 전투에 집중하기 쉬운가?
