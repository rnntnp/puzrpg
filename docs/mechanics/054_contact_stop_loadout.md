# 054 · 능력 편성 / 역중력 드롭

Status: `NEEDS_PLAYTEST`

## 행동 계약

- 사용자 요청에 따라 54번을 기본 드롭 물리의 역중력 버전으로 변경한다. 2스테이지의 기본 마찰·반발·감쇠·질량·합성 충격파·합성 연출을 사용하며 중력 부호만 반대로 적용한다. 빙결 적 규칙을 복제하는 것은 아니다.
- 마우스 이동 또는 터치 드래그로 가로 위치만 고르고 놓는다. 아래쪽에서 초기 속도 0으로 생성된 공이 위로 떨어져 천장 아래에 쌓인다. 방향·파워 조준, 발사 화살표, 발사구 칸막이는 없다.
- 기본 스테이지와 같은 가이드선을 공 미리보기에서 위쪽 천장까지 표시한다. 가로 위치를 따라 이동하며, 기본 드롭 가능 상태에 맞춰 공 미리보기와 함께 표시·숨김 처리한다.
- 벽과 공 충돌은 일반 물리로 처리한다. 강제 정지·고정은 없고, 합성 결과는 원본 평균 속도를 계승한다. 합성 충격파는 기본값 110이다.
- 천장과 공 접촉은 착지이며 옆 벽은 착지가 아니다. 기존 첫 착지 이후 입력 재개, 500ms 합성 정리, 최대 4초 턴 완료를 사용한다.
- 위험선은 아래쪽에 배치한다. 착지한 공의 중심이 선 아래로 넘치면 기존 경고·타이머·초과 공 제거·피해 규칙을 적용한다. 위험선을 억제하지 않는다.
- 기존 세 적, 능력 편성, 점수·피해·콤보·게이지·쇠약과 적 전환 처리는 유지한다. 적 전환 동안 공 배치가 이어진다. 별도 Break는 없다.
- 종료·패배·재시작·핸들러 교체에서 공 중력, 입력, 가이드와 위험선 방향·위치를 복구하고 천장을 제거한다.
- 화면은 `54. 고요한 연못`으로 표시한다. 1스테이지의 분할 배경과 간결한 화면을 유지한다. 설명·디버깅 문구는 표시하지 않는다.

## 중복 확인 및 구현

51번은 아래 중앙에서 방향을 정해 발사한다. 54번은 초기 속도 없이 가로 위치를 선택해 위로 떨어뜨린다는 차이가 있다. 52번의 위쪽 발사와 53번의 무중력 마찰 던지기와 구별된다. 사용자 지정 비교 실험이므로 새로운 적 규칙은 추가하지 않는다.

기존 능력 편성 핸들러, 적 순서, 공 물리 Resource, 합성·턴·피해·위험 타이머를 재사용한다. 호환을 위해 54번의 기존 `test_contact_stop_loadout.tres`, `contact_stop_config.gd`, `contact_stop_merge_loadout_handler.gd`, `contact_stop_launcher.gd` 경로는 유지한다. 전용 설정에는 천장 두께 24, 아래쪽 생성 여백 18을 둔다. 공유 위험 판정에는 높이 방향 값만 추가하며 기본값은 기존 위쪽 초과 판정이다.
