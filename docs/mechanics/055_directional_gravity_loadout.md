# 055 · 능력 편성 / 방향 중력 발사

Status: `NEEDS_PLAYTEST`

## 행동 계약

- 53번처럼 아래 중앙에서 드래그 방향·길이로 방향과 세기를 정하고 놓으면 발사한다. 조작 가능한 방향은 위쪽 반원이다.
- 발사한 공은 다른 공·천장·바닥에 닿기 전까지 진행 방향으로 중력을 받는다. 중력 크기, 질량·감쇠와 공끼리의 충돌은 기본 스테이지와 같다. 옆 벽만 마찰 0·반발 1로 설정한다. 처음 속도와 중력 방향이 같으므로 다른 힘이나 충돌이 없다면 직선으로 이동한다.
- **사용자 확인:** 천장·바닥·다른 공과 처음 충돌하면 해당 공도 수직 위쪽 중력으로 전환한다. 기존 공과 합성 결과는 항상 위쪽 중력을 받는다. 전환 시 속도를 강제로 0으로 만들거나 공을 고정하지 않는다.
- 옆 벽에서는 입사각과 반사각이 같도록 탄성 반사한다. 옆 벽에 튕길 때마다 중력 방향도 같은 각도로 반사되어 직선 이동을 유지한다. 발사 공은 공이나 천장에 닿기 전까지 회전을 잠가 하트 공도 벽 접촉으로 회전 에너지를 얻지 않게 한다. 다른 공·천장 접촉 또는 정리 시 원래 회전 설정을 복구한다.
- 가이드는 현재 공의 실제 충돌 모양으로 이동을 검사하고, 중력도 함께 반사되는 직선 경로를 벽 충돌마다 이어 표시한다. 다음 공·천장·바닥 충돌 예상 위치에는 원을 표시한다. 최대 6초·8회 반사까지 예측하며 한도에 도달하면 도착 원 없이 경로만 표시한다. 움직이는 다른 공의 미래 위치나 공끼리 충돌한 뒤 최종 정착은 예측하지 않는다.
- 첫 옆 벽 충돌도 착지로 처리한다. 첫 착지 후 입력 재개와 500ms 합성 정리, 4초 최대 턴 완료를 재사용한다. 먼저 발사한 공이 비행 중에 다음 공이 생겨도 각 공이 다른 공·천장·바닥에 닿을 때까지 방향 중력을 독립적으로 유지한다.
- 기본 합성·결과 속도 계승·충격파·점수·콤보·피해·스킬 게이지·쇠약과 능력 편성을 유지한다. 최대 단계끼리는 합성하지 않는다. 별도 Break는 없다.
- 레벨 데이터의 `is_gimmick_test_level = true`에 따라 플레이어와 적 모두 무한 체력이며 양쪽 체력바에 `∞`를 표시한다. 공격·피격 연출·능력은 유지하고 HP로 죽지 않는다. 테스트 여부를 끄면 양쪽 일반 HP와 기존 세 적 진행으로 돌아간다. 기믹 자체의 별도 실패 조건은 유지한다.
- 54번처럼 아래 위험선에 착지한 공이 넘치면 기존 경고·시간·초과 공 제거·피해를 적용한다. 위험선을 비활성화하지 않는다.
- 마지막 적 처치·패배·재시작·장면 종료·핸들러 교체 시 공 중력과 힘, 회전 잠금, 옆 벽 재질, 접촉 신호, 입력·가이드·위험선 설정을 복구하고 임시 천장과 착지 표시를 제거한다. 합성으로 삭제된 공은 유효성 검사 후 건너뛴다.
- 1스테이지 연못 배경과 간결한 화면을 유지한다. 제목은 `55. 흐르는 연못`이며 안내·디버깅 문구는 추가하지 않는다.

## 중복 및 재사용

51번은 처음부터 위쪽 중력을 받는 방향 발사, 53번은 무중력 마찰 던지기, 54번은 위쪽으로 수직 드롭이다. 55번은 발사한 공만 공·천장·바닥 접촉까지 방향 중력을 받고 벽 반사 후 경로까지 미리 보여준다는 차이가 있다. 사용자가 지정한 물리 비교이므로 후보 생성과 별도 적 규칙 확장은 생략한다.

54번의 천장·위험선·중력 복구와 기존 능력 편성 핸들러, Stage/적 순서/턴/합성/피해를 재사용한다. 전용 시각 계층이 입력·힘·충돌 예측을 소유한다. Battle, MonsterActionController와 공유 공 물리에는 신규 기믹 분기를 추가하지 않는다.

설정: `scripts/gimmicks/configs/directional_gravity_config.gd` 및 `resources/levels/test_directional_gravity_loadout.tres`. 발사 속도 390–960, 최대 드래그 길이 300, 예측 충돌 여백 0.5, 합성 충격파 110. 천장 두께 24, 생성 바닥 여백 18은 54번 설정을 상속한다.

## 플레이 확인

- 빈 보드에서 비스듬하게 쏠 때 벽마다 가이드와 같은 각도로 직선 반사되고, 공이나 천장에 닿으면 위쪽 중력으로 전환되는가?
- 기존 공을 겨냥한 표시가 실제 첫 충돌과 충분히 일치하는가? 하트 단계와 밀집된 배치도 확인한다.
- 합성 결과와 기존 공은 수직 위쪽 중력을 유지하고 정상 연쇄·피해가 발생하는가?
- 테스트 표시가 켜진 상태에서 양쪽 무한 체력이 유지되며, 재시작과 다른 스테이지 이동 시 설정이 남지 않는가?

정적 검증: Godot 4.7.1에서 신규 레벨과 의존 스크립트 로딩, 적 3명과 설정값, 표시·테스트 카탈로그 등록을 확인했다. 신규 참조 경로와 변경 파일 공백 검사도 통과했다. 실제 조작감·예측 정확도·게임 완료는 사용자 플레이테스트가 필요하다.
