# 056 — 수박 던전 / 웨이브 카드 선택

상태: `NEEDS_PLAYTEST` · 요청: Suika Dungeons를 참고한 우파루파 스테이지 하나.

## 참고 범위와 차이

[공식 소개](https://play.google.com/store/apps/details?id=com.SillyCode.SuikaRougeLike)에서 확인한 합성 자동 투사체, 웨이브 사이 보드 유지, 무작위 3장 중 1장 선택, 공격·치명타·번개·도탄 빌드를 재현한다. 실제 앱 플레이나 원작 수치 검증은 하지 않았다. 원작 아트 대신 프로젝트의 우파루파·수정 동굴·기존 적 아트를 사용한다.

단일 스테이지 5웨이브로 축소했다. 다수의 동시 적, 영구 카드 해금·강화, 상점, 무한 던전은 포함하지 않는다. 기존 단일 적 전투에 맞춰 도탄은 같은 적에게 되돌아오는 추가 피해/궤적이다. 갑옷과 분노는 우파루파 프로토타입의 명시적 각색이며 원작의 확인된 적 규칙으로 주장하지 않는다.

중복 확인: 51–55의 사전 단계별 능력 편성 대신 **전투 중 무작위 보상으로 이번 도전의 빌드를 누적 선택**한다. 24의 연쇄별 피해와 일부 겹치는 갑옷은 보조 규칙이다. 일반 낙하·물리·합성·턴·위험선의 공통 규칙을 바꾸지 않는다.

## 플레이 계약

- 가로 위치를 정해 위에서 떨어뜨린다. 같은 단계 합성, 결과 공, 연쇄 배율, 정상 투사체를 그대로 쓴다.
- 적 5명을 기존 적 순서 시스템으로 상대한다. 플레이어는 기존 100 HP, 적 HP는 180 / 300 / 480 / 650 / 1100. 테스트 목록에 등록하지만 `is_gimmick_test_level=false`이므로 양쪽 HP가 유한하며 승패가 있다.
- 1–4웨이브 처치 후 다음 적 구성 시 카드 3장을 중복 없이 추첨한다. 최대 등급 미만의 카드 중 균등 추첨하고 한 장을 고르면 즉시 적용한다. 재추첨·건너뛰기는 없다. 같은 카드는 최대 3등급. 후보가 3장 미만이면 남은 후보만, 없으면 보상 없이 진행한다.
- 선택 중 보드 입력·물리·투사체 이동·위험선이 일시정지된다. 이미 예약된 합성의 타이머 콜백은 완료될 수 있지만 투사체는 선택 후 움직인다. 선택 해제 시 이전 보드로 재개한다. 보상을 빠르게 중복 클릭해도 한 번만 지급한다.
- 공과 HP, 카드 등급, 번개 적중 누적은 다음 웨이브에 유지한다. 적 반격 카운트만 초기화한다. 보스 처치 뒤에는 추가 카드 없이 기존 승리 화면으로 이동한다. 재도전하면 모든 카드와 누적 적중은 초기화된다.

| 카드 | 등급당 효과 |
|---|---|
| 강타 | 합성 피해 +25% (합산) |
| 치명타 | 확률 +20%로 피해 ×2 |
| 번개 | 소유한 이후 합성 공격 3회 적중마다 18 × 등급 추가 피해 |
| 도탄 | 강타·치명타 적용 피해의 30% × 등급을 같은 적에게 추가 |
| 생명 흡수 | 합성 적중마다 등급만큼 HP 회복, 최대 HP 제한 |
| 돌가죽 | 적 반격을 2 × 등급 감소, 최소 0; 넘침에는 적용하지 않음 |

공격 적중 시 현재 카드와 투사체에 저장된 연쇄 수를 읽는다. 계산 순서: 기본 합성 피해 → 강타 → 치명타 → 도탄 및 번개 합산 → 적 갑옷 → 기존 Weakness. 반올림은 각 단계에서 적용한다. 번개/도탄은 원래 타격에 합산하여 기존 피해 집계와 사망 흐름을 한 번만 통과한다. 별도의 합성·점수·게이지를 만들지 않는다. 치명타/번개/도탄/갑옷 피드백 숫자는 Weakness 적용 전 값이다. 기존 투사체의 기본 피해 표시는 카드 보정 전이며 실제 HP 피해는 기존 피격 표시를 따른다.

## 학습과 적 구성

| 웨이브 | 반격 | 규칙과 예상 대응 |
|---|---|---|
| 1 입구 | 4턴 / 4 피해 | 일반 적. 합성 위치를 익히고 첫 보상을 획득한다. |
| 2 동굴 | 3턴 / 5 피해 | 첫 카드가 적용되는 일반 전투. 회복·방어와 공격 투자의 차이를 확인한다. |
| 3 정예 | 4턴 / 7 피해 | 1연쇄 타격은 65% 피해, 2연쇄 이상은 갑옷 무시. 같은 단계 쌍 근처에 떨어뜨려 연쇄를 준비한다. |
| 4 심층 | 2턴 / 7 피해 | 빠른 반격. 보드의 큰 합성 준비와 당장 회복/공격 사이를 선택한다. |
| 5 군주 | 3턴 / 10 피해 | 정예 갑옷 + HP 50% 이하에서 반격 ×1.5. 누적 카드와 연쇄로 분노 구간을 돌파한다. |

반격과 분노 피해는 행동 직전에 판정하며 남은 턴·예상 피해를 표시한다. 분노는 현재 HP로 결정하므로 임계 HP를 깎은 직후 표시도 갱신한다. 추가 피해/치명타의 임의성은 카드 선택과 합성 배치를 대체하지 않는다.

## 공통 규칙·경계·정리

- Skill Gauge는 정상 합성 점수만큼 한 번 충전, 보너스 피해로 추가 충전하지 않는다. 기존 플레이어 Weakness 유지. 공용 Break 없음.
- 위험선 위치·시간·제거·넘침 피해는 기존 규칙. 카드 모달이 닫히면 기존 카운트로 재개한다. 전투 중 지속 억제 없음.
- 적 전환 중 드롭/합성은 기존 보류 공격 및 턴 귀속 규칙을 쓴다. 보상 직전에 발사됐으나 적중하지 않은 공격은 적중 시점 카드로 계산한다. 적중하지 않고 폐기된 공격은 번개 누적/흡혈을 주지 않는다.
- 이미 죽은 적·플레이어에는 카드 효과를 적용하지 않는다. 대상 동률은 단일 적 전투라 해당 없음. 최종 합성은 정상 공격/사망 경로만 사용한다.
- 적 전환은 카드·보드를 보존하고, 최종 적 사망/장면 종료/재시작은 카드·UI·시각 효과·Tween을 폐기한다. 핸들러 정리 시 체력 시그널과 예측 표시를 해제한다. 카드 모달이 소유한 일시정지는 정리 또는 장면 이탈 시 반드시 해제한다.

## 구현·튜닝·확인

- 레벨 선택 마지막의 **56. 수박 던전**. `resources/levels/test_suika_dungeon.tres`에 적 배열, HP, 배경, 유한 체력 설정.
- `scripts/gimmicks/configs/dungeon_draft_config.gd`: 카드 수치·웨이브 이름/공격/간격·갑옷·분노. 레벨의 `test_gimmick.tuning` Inspector에서 조절.
- `scripts/gimmicks/handlers/dungeon_draft_handler.gd`: 기존 `TestGimmickHandler`를 확장한 보상/피해/턴 처리.
- `scripts/gimmicks/visuals/dungeon_draft_visual.gd`: 독립 카드 선택 레이어·보유 빌드·번개/도탄 표시. 색/텍스트/선 기반으로 기존 아트 재사용.
- 기존 Battle 적 순서/승패, MergeGame 물리/합성, Fighter HP, TestGimmickController 보존 전환, 카탈로그 등록을 재사용한다. 공유 전투 클래스와 Legacy 핸들러에는 분기를 추가하지 않는다.
- 2026-10-05 정적 확인 완료: 설정/시각 스크립트 `--check-only` 통과. 핸들러의 직접 `--check-only`는 공통 Battle의 자동 로드 참조(GameSession) 때문에 단독 컴파일을 지원하지 않아, 전투를 생성하지 않는 임시 SceneTree 검사로 자동 로드 문맥에서 신규 레벨 Resource와 핸들러 컴파일을 확인했다. 적 5명, HP 배열, 유한 HP, 보드 보존, 튜닝 길이, 가시/테스트 카탈로그 각 1회 등록을 확인했다. 전역 검사·회귀·실제 플레이·재미/밸런스 검증은 하지 않았다.

플레이테스트 질문:
1. 각 웨이브 뒤 선택 창에서 공/투사체가 멈추고, 선택 후 정상 재개되는가?
2. 카드 조합에 따라 공격형/생존형 선택의 차이를 체감하는가?
3. 정예의 2연쇄 관통과 보스의 반격 증가를 읽고 대응할 수 있는가?
4. 보스를 쓰러뜨리거나 패배한 뒤 재시작하면 카드/일시정지가 남지 않는가?

후속 확장 후보: 합성 위치별 카드, 특정 단계 특화 카드, 연쇄로 충전하는 선택형 스킬. 이번 구현에는 포함하지 않는다.
