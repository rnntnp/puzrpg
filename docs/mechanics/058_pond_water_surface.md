# 058 — 맑은 물방울 연못

상태: `NEEDS_PLAYTEST`. 사용자 요청으로 57번의 새 물방울 셰이딩을 별도 비교 스테이지로 분리했다.

- 55·57번의 방향 발사, 반사 가이드, 접촉 후 위쪽 중력, 합성·피해·콤보, 능력 편성, 세 적, 배경, 테스트 무한 체력을 재사용한다. 새로운 전투 규칙은 없다.
- 기존 테두리 스프라이트와 캐릭터는 그대로 유지한다. 중앙은 맑게 두고 반사 방향에 타원형 softbox 광택을 표시한다. 굴절·화면 복사·추가 그림자는 없다.
- 주 광택 0.78, 보조 0.22, 타원 비율 2.2. edge=(1−N.z)^4에 방향성 반사 0.12와 반대편 명암 0.16을 적용한다. 이웃 반사 강도는 0.20이다. 57번은 이전 광택 1.0·0.75, 이웃 반사 0.60을 유지한다.
- 기존 11종 실루엣 메시와 노멀맵을 공유한다. 전용 handler/config/visual/shader를 사용하며 종료 시 원래 광택을 복원한다. 이동 중 갱신과 적 전환은 57번 구조를 재사용한다.
- 중복은 의도적인 시각 비교다. 공의 광택·테두리·캐릭터 가독성을 57번과 비교하는 사용자 테스트가 필요하다.
- 튜닝: `scripts/gimmicks/configs/pond_water_surface_config.gd`. 진입: `resources/levels/test_pond_water_surface.tres`.
- MCP에서 57·58번 진입, 서로 다른 표면 셰이더, 동일한 기존 테두리 셰이더, 58번 목록 등록·세 적·테스트 표시를 확인했다. 실행 중 새 스크립트·셰이더 오류는 없었다. 전체 플레이와 성능은 미검증이다.
