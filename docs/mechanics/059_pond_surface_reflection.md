# 059 — 색이 비치는 연못

상태: `NEEDS_PLAYTEST`. 57번의 반사가 발광처럼 보인다는 사용자 피드백에 따른 시각 비교다.

- 57번의 전투·발사·중력·벽 반사·가이드·합성·피해·테스트 무한 체력·세 적·배경을 재사용한다. 기존 테두리와 두 흰 광택도 유지한다. 57·58번은 변경하지 않는다.
- 주변 공의 발광색 대신 실제 시각 노드의 `tint_color`를 사용한다. SG 로브에 smoothstep(0.35,0.65)를 적용해 희미한 꼬리를 없애고 제한된 반사 영역을 만든다. 반사 방향과 크기는 이웃 위치·입체각과 실루엣 노멀에 따른다.
- 주변 공의 원래 색을 그대로 알파 합성한다. 탁해진다는 사용자 피드백에 따라 채도 15% 감소와 밝기 0.72배 처리를 제거했다. 반사 불투명도 상한은 공당 0.60, 노출은 16이며 반사 영역과 세기는 유지한다. 밝은 색의 합산과 정규화가 주변 색을 빛처럼 밝히던 이전 합성 방식을 바꾼다.
- 환경 diffuse 채움을 제거하고 약한 방향성 반사만 남긴다. 실제 거울상·GI·굴절·가려짐을 계산하는 모델은 아니다.
- 전용 config/handler/visual/shader를 사용하고 11종 메시·노멀 리소스를 공유한다. 표면 간 거리 180px 이내에서 입체각×거리 감쇠가 큰 이웃 최대 8개, 겹친 색 반사 전체 불투명도 상한 0.75, 정지 12Hz·이동 30Hz, 종료 시 원래 광택 복원은 57번 구조를 재사용한다.
- 의도적 중복: 같은 상황에서 57번과 색 반사의 경계·밝기·가독성을 비교한다. 조절은 `pond_surface_reflection_config.gd`에서 한다. 사용자 플레이테스트로 반사가 너무 약하거나 딱딱해졌는지 확인한다.
- MCP에서 59번 진입·주변 공 임시 배치·렌더링·전용 셰이더와 불투명도 제한·기존 테두리·57번 강도 유지·목록 등록을 확인했다. 셰이더·스크립트 오류는 없었고 기존 배경 앵커 경고만 있었다. 미술적 개선과 전체 플레이·성능은 사용자 확인이 필요하다.
- 반사 색이 밝다는 피드백에 따라 RGB를 동일하게 0.85배로 조절한다. 채도 감소 처리는 없으며 흰 광택·환경 반사·반사 영역과 불투명도는 유지한다. 전용 설정 reflection_color_brightness로 조절한다.
- 후속 요청으로 반사 색 밝기를 1.0으로 복원하고 채도도 유지한다. 색 반사의 개별 불투명도 상한은 0.60→0.45, 중첩 전체 상한은 0.75→0.60으로 낮췄다. 흰 광택과 반사 영역은 유지한다.
- 8단계 광택의 울퉁불퉁함을 줄이기 위해 높이장에 3×3 평활 필터를 3회 적용하고 메시·노멀을 재생성했다. 노멀은 256×256·반정밀도 형식으로 변경했다. 실제 윤곽·콜라이더·다른 10종 리소스는 유지한다. MCP로 표시와 전체 노멀의 유한성·단위 길이를 확인했다. 공유 리소스이므로 57~59번에 반영된다.
- 렌더링 설정을 resources/visuals/pond_surface_rendering_settings.tres로 분리했다. 레벨 튜닝이 이를 참조하고 시각 레이어는 렌더링 리소스만 읽는다. 반사 불투명도·두 광택 광원·환경·거리·갱신 값을 저장하며 게임 규칙 값과 분리한다. MCP에서 리소스 참조와 실제 셰이더 전달 값(0.45, 1.0, 0.75)을 확인했다.
