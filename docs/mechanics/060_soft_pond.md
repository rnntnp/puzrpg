# 60. 말랑한 연못

## Current backend: official QuarkPhysics, 12 independent particles

- Windows x64 now loads the original official v1.0.7 release DLL. No native affine binding API or modified contact/area solver is used. Each original convex outline is sampled at 12 equal arc-length positions. Those same 12 particles form the physical collision boundary; 12 perimeter + 12 next-neighbor + 6 opposite springs, 30 total. GPU uses 12-point deformation; guide queries use the deformed convex hull.
- Removed custom post-solve deformation/contact damping, floor/ceiling rebound retention, energy projection and hard spring distance limits. Native rigidity/shape/area/friction/sleep settings only. quark_air_damping=0.65/s maps to native air_friction and guide integration; it slows translation as well as deformation. Explicit elastic directional side reflection remains the inherited gameplay rule.
- Parameters: count 12 (8/12/16 selectable), 2 substeps × 4 iterations, rigidity 0.4, shape 0.8, area 1.0, ball/wall friction 0.01/0.19, native restitution 0, sleep tolerance 0.025. XPBD fallback parameters remain unchanged.
- Scoped MCP: official binary lacks bind_material; native mesh has exactly 12 particles/30 springs. Eleven catalog ball types finite and visually rendered. Live same-level merge produced level index 1 and can_drop=true. First wall guide comparison over 64 ticks maximum distance 4.58px. Small ceiling shot after 600 ticks was not sleeping, control drift over next 120 ticks 0.39px; full stillness is not solved. 48-ball 3s profiler frame elapsed average 70.43ms, physics average 14.72ms, still heavy; not a CPU-only or FPS guarantee. NEEDS_PLAYTEST.

- Parameter-only resistance retune: 12-point baseline rigidity/shape/area 0.25/0.04/0.8 → 0.4/0.12/1.0. No code changes. Large ceiling peak edge strain 10.7→7.9%, small ceiling tail deformation RMS 8.75→0.95px/s, floor 8.88→0.56px/s. Stronger rigidity 0.6/0.8 reintroduced small-ball vibration and was rejected. Ten fixtures repeated twice; live merge/can_drop rechecked. See comparison document for historical XPBD/six-control values and limits.

- Latest deformation-focused resource retune: shape matching 0.12→0.8 and native air damping 1.2→0.65/s. Same-outline displacement (rigid motion removed, normalized by radius) replaces edge strain as the comparison metric. Head-on peak 6.7→10.3% against XPBD 12.3%; stack peak 20.2→17.6% against 18.2%. Large ceiling/free recovery still differ. Two repeated sets of 10 fixtures and live merge checked. No runtime code added; comparison document contains remaining mismatches.

## Historical six-control binding implementation (superseded)

## Preserved XPBD implementation and prior measurements

- Contract: 공의 원래 형태·면적 유지와 겹침 방지를 같은 XPBD 반복 안에서 계산한다. 순간 충격은 감쇠 복원, 지속 압력은 눌린 평형 상태, 자유 상태는 원래 형태. 접촉 충격량으로 콜라이더를 재변형하는 이전 피드백 모델은 제거했다.
- Reuse: 59번 반사/테두리/배경/캐릭터/방향 발사/중력/가이드, 테스트 양측 체력 무한. 기존 질량, 합성 요청/결과/피해/충격 전달 경로 유지. 합성 공 자동 등록.
- Solver: 원본 히트박스 외곽의 볼록 껍질을 호 길이 기준 6점으로 샘플링. 외곽과 내부 거리 제약, 면적 제약, 벽 및 공 접촉을 반복 계산. 거리 제약의 compliance는 외곽 0.002/내부 0.006, 면적 0.000001. XPBD 누적 lambda는 소구간 내 반복에서 유지하며 소구간마다 초기화한다. 거리 변형 제한 10%.
- Integration: 고정 60Hz 재질 계산, 기본 2소구간으로 입자 적분 120Hz, 반복 8회. 중력 방향/constant_force/질량과 외부 강체 impulse를 가져와 입자에 적용한다. 내부 상대 운동 감쇠 18, 기존 선형/회전 감쇠 연결. 근접 후보는 소구간별로 한 번 생성한다.
- Contacts: 실제 변형 외곽의 볼록 껍질을 Godot 네이티브 Shape2D 접촉 쿼리로 검사, 가까운 지지점의 접촉 패치에 위치 보정 분배. Godot 강체 접촉 solver는 이 레벨 공에서 제외한다. 변형 콜라이더는 가이드 쿼리에 계속 노출한다. 접촉 시작 신호를 기존 발사기/착지/합성에 전달한다. 옆 벽 탄성 반사, 수평 면 반발 0.02, 미세한 정지 접촉에는 반발을 적용하지 않는다.
- Rest: 접촉 시스템의 입자 RMS 속도 12px/s 및 중심 속도 6px/s 미만이 0.75초 유지되면 시스템 전체 수면. 자유 공은 거리 제약의 잔차까지 충분히 작아야 수면 가능하다. 새 공, 외부 impulse, 중력/힘 변경, 외부 재배치 또는 공 제거는 시스템을 깨운다. 공별로 엇갈리게 수면 처리하지 않는다.
- Rendering: 공유 메시/GPU vertex shader 유지. 중심과 인접 제어점의 삼각형 선형 보간으로 원본 윤곽 및 테두리/캐릭터/셰이더 반사를 변형한다. ShellGloss 스프라이트는 프록시 복제에서 제외한다.
- Cleanup: 원본 custom_integrator/collision mask/layer/CCD 및 충돌 활성 상태 복구, 임시 콜라이더와 GPU 프록시 제거. 이전 스프링 helper 및 사용하지 않는 튜닝 제거.
- Scoped MCP (16점 이전 버전): 실제 적층 두 공의 수면 후 2초 외곽점 이동 0, impulse 후 재활성 확인. 자유 상태에서 6px 외곽 변형을 준 뒤 원본 대비 오차 약 0.001px로 복원. 같은 1단계 두 공이 기존 합성 경로로 2단계가 됨. 스프라이트 광택 프록시 없음 및 cleanup 복구 확인. 신규 runtime/shader 오류 없음.
- Scoped CPU (16점 이전 버전): 작은 공 20개, 접촉이 적은 임시 배치에서 120Hz 호출 30회의 평균 약 3.77ms/호출(60Hz 실행+건너뛰는 호출 포함), 전체 solve는 약 7.5ms. 수면 중 계산 감소. 밀집한 큰 공/전체 FPS/GPU 부하는 별도 측정하지 않았다.
- Limitations: 볼록 외곽 근사이며 찢김·심한 접힘·자기 충돌은 지원하지 않는다. 국소 GPU 변형 보간은 입자 기반 충돌 외곽과 같은 입력을 사용하지만 원본 스프라이트 전체 픽셀의 정확한 물리 경계는 아니다. 조작감/자연스러움/밀집 보드 성능은 NEEDS_PLAYTEST.

- 6-point retune: 물리 외곽점만 16 → 6으로 축소. 렌더 메시 GRID=10과 원본 스프라이트/광택 해상도 유지. 셰이더는 활성점 6개만 보간하며 uniform 배열은 호환 용량 16 유지. 두 공 적층 MCP: 각각 6점, 약 4.3초 후 수면, 이후 2초 외곽점 이동 0. 충돌 외곽은 더 거친 볼록 다각형 근사.

- Landing fix: 합성 처리의 body_entered가 두 원본 공을 즉시 잠그기 전에, 모든 접촉 쌍의 양쪽 first_contact를 먼저 전달한다. 수정 전 발사 공이 merge_locked=true/착지=false/can_drop=false로 남는 상황 재현. 수정 후 동일 조건 6회에서 착지 및 다음 발사 가능 확인.
- Broadphase: 128px 공간 격자에 예측 이동 여유를 포함한 외곽 AABB의 모든 겹친 칸을 등록한다. 같은 쌍은 한 번만 후보화. 근접 후보만 SAT/제약 반복. 보통 O(n+k), 밀집 시 최악 O(n²). 큰 공과 음수 좌표/셀 경계를 포함한 48개 합성 표본을 전수 AABB 비교 기준과 대조해 후보 누락/중복 0 확인.

- Dense silhouette: 물리 자유도는 6점 유지, 충돌 윤곽은 원본 히트박스의 볼록 외곽 33~60점 사용. 원본 외곽을 중심·인접 제어점 삼각형에 연결하여 원래 곡선의 위치를 보존한다. 공 SAT/벽/공간 격자 AABB/가이드 콜라이더가 모두 같은 변형 윤곽을 사용하며, 접촉 보정은 연결 가중치의 유효 질량으로 6점에 분배한다. GPU도 동일한 보간식 적용.
- Dense scoped MCP: 11종 모두 제어점 6개, 원래 외곽 대비 최대 정점 오차 0.00013px 미만. 적층 두 공은 약 3.4초 후 수면, 이후 2초 윤곽 이동 0. 신규 런타임/셰이더 오류 없음. 종전 6점 콜라이더 및 CPU 수치는 이전 버전 기록이다.

- Dense final scoped CPU: 같은 작은 공 20개 배치에서 120Hz callback 30회 평균 3.12ms(60Hz solve와 skip 포함). 천장 노드 탐색 및 보드 변환을 캐시하고 비접촉 AABB를 SAT 전에 제외한다. 이 수치는 전체 FPS나 밀집 큰 공 측정이 아니다. 변경 후 정상 합성 및 다음 발사 가능도 재확인.

- Dense collision optimization: GDScript의 모든 변 축 × 모든 정점 SAT 루프를 제거하고 Shape2D.collide_and_get_contacts 사용. 변형된 볼록 쿼리 도형을 캐시한다. 접촉 방향·지지점 가중치는 소구간 동안 재사용하며 반복에서는 6개 제어점의 접촉 위치로 깊이만 갱신한다. 소구간마다 접촉을 다시 구하고, 아직 접촉하지 않은 후보는 반복 중 새 접촉을 계속 검사한다. 원본 촘촘한 윤곽과 6개 자유도 유지.
- Dense profile: 큰 공 단계 2/5/6/7을 4×4로 놓은 16개 밀집 fixture, 합성 연결을 임시 해제하고 MCP profiler 3초 측정. 수정 전 충돌 함수 inclusive 프레임 비중 91.5%, 평균 프레임 처리 527.7ms. 네이티브 쿼리+소구간 manifold 캐시 후 평균 46.1ms, 충돌 호출 평균 0.2699→0.0116ms. catch-up 물리 tick과 서로 다른 진행 속도가 포함된 실시간 측정으로, 전체 게임 FPS 보증은 아니다. 밀집 시 윤곽 재생성/벽 제약 비용이 남는다.
- Optimized scoped MCP: 적층 두 공 수면 후 240 physics ticks 윤곽 이동 0px, 외부 impulse 후 재활성. 같은 1단계 공 접촉 후 합성 결과 및 발사 가능 확인. 신규 script/shader 오류 없음. 자연스러움은 NEEDS_PLAYTEST.
- Batch surface / wall cache: 원본 외곽 연결을 6개 삼각형 구역으로 한 번 정렬하여 PackedVector2Array에 저장. 동일한 선형 보간을 Transform2D의 네이티브 배열 변환으로 일괄 처리한다. 벽 지지점 패치도 소구간마다 갱신하고, 반복 중에는 6점 가중 접촉 위치와 평면 거리만 계산한다. 60Hz/2소구간/8회 반복 및 촘촘한 원본 윤곽 유지. 지지점 선택은 소구간 내 고정되는 근사다.
- Batch scoped profile: 같은 16개 큰 공 밀집 fixture, MCP profiler 3초 평균 프레임 처리 46.1→13.59ms, 최대 18.52ms, script 평균 9.96ms. 이전 버전은 느린 프레임의 physics catch-up이 포함되므로 개별 solver 비용 감소율과 전체 프레임 감소율은 같지 않다. 전체 게임/다른 장치의 FPS 보증이 아니다.
- Batch scoped MCP: 적층 두 공 수면 후 240 physics ticks 윤곽 이동 0px, impulse 재활성, 같은 단계 합성 결과 및 can_drop=true 확인. 배열 일괄 변환과 원래 선형 보간식 최대 차이 0.000069px 미만(검사한 합성 결과 공). 신규 script/shader 오류 없음. 밀집 배치의 조작감은 NEEDS_PLAYTEST.
- Merge penetration energy: 합성 결과의 커진 윤곽이 이웃과 겹칠 때 위치 보정이 (points-previous)/dt 속도로 바뀌어 운동 에너지를 만들던 경로 수정. 실제 지지점 상대 접근 속도×dt와 1px 수치 허용치보다 큰 침투는 previous에도 보정 분량을 반영하여 안정화 이동으로 분리한다. 접촉 중 공들의 중심 이동 에너지는 중력·외력·합성 impulse가 반영된 predict 단계 예산 이하로 투영한다. 내부 상대 변형 속도는 유지한다. 합성 push 강도/크기 배율/감쇄 공식은 유지. 이 보호는 중심 이동에 대한 소산 모델이며, 물질 탄성 에너지가 중심 이동으로 변환되는 효과도 제한한다.
