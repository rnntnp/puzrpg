# 62. 동글한 연못

Status: `NEEDS_PLAYTEST`

- 59번의 기본 Godot 강체 물리와 방향 발사를 재사용한다. 아래에서 위로 조준·발사하고, 벽 반사와 접촉 후 위쪽 중력 전환을 유지한다. 원래 종별 고정 충돌체를 그대로 쓰며 가이드도 그 충돌체를 검사한다.
- 기존 62번의 XPBD, 동적 원 맞춤, 충돌체 교체를 제거했다. 파일/Resource 경로는 기존 레벨 참조를 위해 유지한다. 별도 네이티브 확장은 로드하지 않는다.
- 공의 실제 위치·회전·충돌·합성은 강체 물리가 담당한다. 접촉 정보는 읽기만 하며 변형 결과를 물리에 되먹이지 않는다. 합성·턴·피해·넘침·적 전환은 기존 경로를 재사용한다.
- 접촉 방향과 충격량/상대속도에서 최대 4개 대표 방향을 얻고 기존 XPBD와 동일하게 원래 충돌 외곽의 둘레를 등분한 6개 시각 제어점을 압축·팽창시킨다. 감쇠 스프링으로 복원하고 제어점 변위를 반경의 28% 이내로 제한한다. 접촉 위치에 가까운 제어점에 가우시안 거리 가중치로 눌림·팽창을 분배한다. 다중 접촉은 가중 평균하여 과도한 합산을 막는다. 6개 점만 스프링으로 움직이고 기존 부채꼴 삼각형 보간으로 그림 전체를 변형한다. 정점별 접촉 평면 제한은 제거했다. 실제로 눌려 좁은 틈을 통과하는 소프트바디는 아니다.
- 와핑 범위는 등록된 MergeBall의 VisualContainer 내부 그림/메시뿐이다. 배경, 벽, 적, UI, 가이드에는 적용하지 않는다. 재질을 공별로 복제하고 메시·셰이더를 공유한다. 윤곽에 통합한 반사는 유지하며 별도 반사 메시를 추가하지 않는다.
- 시각 갱신은 최대 60Hz, 마지막 공개 좌표에서 0.01px 이상 바뀌거나 새 그림이 설치될 때만 셰이더 값을 갱신한다. 얼음 공은 목표 변형을 0으로 복원한다.
- 전용 수치: `resources/circle_xpbd_pond_physics.tres` / `circle_xpbd_pond_config.gd`. 기본 눌림 18%, 충격 추가 12%, 스프링 강도 240, 감쇠 16.
- 공 제거 시 상태를 버리고, 정리 시 관찰 콜백·원본 재질·표시 상태를 복원한다. 콜백에서는 접촉 값만 복사하고 노드 변경은 하지 않는다.

## 검증

2026-11-08 MCP: 천장 충돌에서 시각 변형 발생, 기존 충돌 Shape RID 유지, 기본 강체 상태 및 위쪽 중력 유지, 공 밖의 와핑 프록시 0개 확인. 가이드 표시와 관찰 콜백/그림 복원 확인. 11종 모두 시각 프록시 설치, 발사기 실제 호출에서 하단 출발·상향 속도 확인. 공 제거 시 잘못된 참조 접근을 수정한 뒤 재검사에서 스크립트 오류 없음. 실제 조작감·시각 품질과 모바일 실기기는 사용자 플레이 확인이 필요하다.

## 비용

대표 접촉 H≤4, 시각 제어점 K=6, 공 N개일 때 CPU 변형 계산 O(NKH), 메시 정점 M개당 GPU 변형 O(MK). 엔진의 강체 충돌·가이드·반사 비용은 별도다. 공끼리의 접촉을 와핑 코드에서 다시 검사하지 않는다. 접촉 수집은 엔진이 보고한 접촉 수에 비례한다.

## 158개 측정 (2026-11-08)

MCP, Apple M1, Godot 4.7.1, 동일 시드 61080/1단계 공 158개 배치와 초기 속도, 합성·넘침 억제. 활성 구간 각 5초씩 2회. 기존 62번의 동적 원+XPBD는 앞선 측정 1.84–1.91 FPS였고, 새 강체+와핑은 43.47 / 49.33 FPS였다. 물리 모델 변경으로 이후 궤적은 서로 다르다.

- 전체 평균 프레임 시간: 23.00 / 20.27ms, p95 46.15 / 36.74ms.
- 와핑 레이어 갱신 1회 평균: 5.895 / 5.893ms, p95 6.344 / 6.290ms. 엔진 강체 물리와 접촉 관찰 콜백은 이 타이머 밖이다.
- 와핑 상태 갱신만 정지: 59.36 FPS. 강체 물리·접촉 관찰·반사·기존 변형 그림 렌더링은 계속 실행하므로 와핑 완전 비활성 기준은 아니다.
- 공 158개, 변형 셰이더 및 통합 반사 158개, 별도 반사 메시 0개 유지.
- 안정적인 60 FPS나 모바일 성능을 달성했다는 의미는 아니다. 사용자 조작감·표현 강도 확인 필요.

- 시각 강화 후 MCP 동일 위치 A/B 캡처: 15개 공/37개 대표 접촉에서 넓은 평탄화·옆쪽 팽창 확인. 최초 강화 시 다중 접촉 팽창의 합산으로 생긴 큰 겹침을 접촉 평면 제한으로 줄였다. 위 성능 수치는 강화 전 버전이며 추가 셰이더 제한의 성능은 재측정하지 않았다.

- 6점 보간 변경 후 MCP 15개 공/37개 대표 접촉 캡처에서 최대 제어점 이동 8.24px 확인. 기존 61번과 62번은 같은 `pond_control_cage.gd`의 원본 외곽 샘플링을 사용한다. 공유한 것은 초기 6점 배치뿐이며 62번은 XPBD를 실행하지 않는다. 이 버전의 158개 성능은 아직 재측정하지 않았다.
- 6점 후속 MCP 검사: 11종 모두 제어점/변위 배열 길이 6, 상향 발사·충돌체 RID 유지·공 밖 프록시 0개·콜백/시각 복원 확인. 접촉을 제거하고 1초 후 잔여 제어점 변위 0.000374px. 스크립트/셰이더 오류 없음.
