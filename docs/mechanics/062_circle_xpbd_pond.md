# 62. 동글한 연못

Status: `NEEDS_PLAYTEST`

- 59번의 기본 Godot 강체 물리와 아래→위 방향 발사, 고정 충돌체·가이드·합성·턴·적 전환을 유지한다. 공통 공간 와핑은 사용하지 않는다.
- 공별 6점 와핑을 유지하되 접촉 처리를 단순화했다. 공마다 원 중심·반경을 원래 외곽에서 한 번 구한다. 주변 공의 원 접촉점 두 개와 분담률에 따른 공통 목표를 와핑 전에 계산하고, 각 접촉점의 6점 보간 가중치를 저장한다. 원형이 아닌 공도 시각 접촉 계산에서는 이 원 근사를 사용한다.
- 와핑 후 계산한 접촉점이 같은 목표에 가도록 6개 변위만 조정한다. 기본 2회이며 윤곽 표본을 반복 검색하지 않는다. 강체 접촉 정보는 접촉 여부·충격 세기에 재사용한다. 떨어진 근사 원은 시각 효과만으로 당기지 않는다.
- 벽은 원의 네 방향 키포인트와 6개 제어점만 제한한다. 셰이더 정점별 잘라내기는 없다. 이것은 접촉 키포인트를 맞추는 근사로, 그림 전체의 픽셀 단위 무관통을 보장하는 방식은 아니다.
- 적용 범위는 공 VisualContainer 안뿐이다. 배경·벽·적·UI·가이드는 변형하지 않는다. 물리 몸체의 위치·속도를 와핑으로 변경하지 않는다. 통합 반사와 원본 재질·콜백 복원 유지, 네이티브 확장 없음.
- 튜닝: `resources/circle_xpbd_pond_physics.tres` / `circle_xpbd_pond_config.gd`. 기본 눌림 18%, 충격 추가 12%, 복원 강도 240/감쇠 16, 접촉 시작 보간 0.16초, 접촉 해제 필터 시간상수 0.18초, 벽 여유 1px, 접촉 보정 2회.

11종 공의 와핑·고정 충돌체, 하단 상향 발사, 공 밖 프록시 0개, 복원·정리도 확인했다. 최종 실행에 스크립트/셰이더 오류 없음. 같은 순간의 와핑 켜짐·꺼짐 화면도 캡처했다. 이전 윤곽 표본 반복 보정의 같은 158개 측정은 약 28.7ms(계측 시 29.6ms)였다. 현재는 그 반복 검색과 접촉면 지원점 계산을 제거했다. 실제 조작감과 움직임 중 그림 겹침, 모바일 성능은 사용자 확인이 필요하다.

## 비용

공 N, 격자 후보 쌍 P, 근사 접촉 C라면 원 접촉 준비는 보통 O(N+P), 점 보정은 O(C×6×2)다. 메시 전체나 외곽 표본 수가 접촉 보정 비용에 들어가지 않는다. 밀집 시 후보 쌍은 최악 O(N²)일 수 있다.

## 접촉 해제 복원 필터

접촉이 하나라도 사라지면 직전의 최종 보정 모양을 저장하고, 이를 스프링 목표에서 지수 감쇠시킨다. 보정 위치와 어긋나 누적된 스프링 속도는 해제 시 초기화한다. 접촉 중 목표 한도를 넘은 변위를 다음 프레임에 강제로 잘라내던 처리는 제거했고, 정상 목표의 크기 제한과 벽 보정은 유지한다.

MCP 두 공 접촉→상대 공 제거 검사에서 변형 2.00px가 첫 갱신에 0.0084px만 변했고, 잔여 변형은 0.1초 1.67px / 0.3초 0.45px / 0.6초 0.093px / 1초 0.0097px였다. 12px짜리 보정 모양을 필터 시작값으로 그대로 보존하는 것과 속도 초기화도 확인했다. 강체 상태 유지, 스크립트/셰이더 오류 없음. 필터 추가 후 158개 성능은 재측정하지 않았다.

## 접촉 시작 필터

새 접촉은 그 순간의 6점 모양을 저장한다. 접촉점 보정 목표를 이 모양에서 완전한 접촉 목표까지 smoothstep으로 0.16초 동안 보간하고, 눌림 입력 세기에도 같은 가중치를 적용한다. 두 번 보정한다고 필터 강도가 누적되지 않게 목표 자체를 보간한다. 기존 벽 침범 방지와 접촉 해제 복원은 유지한다.

MCP 두 공 검사: 시작 가중치 0→0.03→0.11…→1로 증가했고, 첫 변형은 0px / 약 0.1초 0.236px / 약 0.2초 1.57px / 약 0.3초 2.40px였다. 순간 최대치를 지나 약 2.14px로 가라앉는 스프링 반응을 확인했다. 분리 1초 후 잔여 0.0104px, 이전 접촉 기록 정리, 강체 상태 유지와 스크립트/셰이더 오류 없음. FPS는 재측정하지 않았다.

## 속도 변화에 따른 분담률

기존 절반 분담만 수정했다. 물리 콜백의 직전 속도로 중력·상수 힘·감쇠가 적용된 예상 속도를 구하고, 실제 속도와의 차이를 충돌 응답의 시각적 근사로 쓴다. 짧은 속도 변화는 시간상수 0.10초로 보관하여 120Hz 물리 사이에 60Hz 와핑이 충격을 놓치지 않게 한다.

접촉 법선 방향의 양쪽 응답 크기를 정규화해 분담률을 정하고 25:75 범위로 제한한다. 저속 응답 합이 20px/s 미만이면 50:50으로 돌아간다. 쌍별 비율은 갱신마다 25%씩 보간한다. 동일한 응답은 여전히 절반이며, 이는 같은 재질의 정밀 탄성 해석이 아닌 시각적 근사다. 눌림 세기·스프링·시작/해제 필터와 강체 물리는 변경하지 않았다.

MCP: 같은 응답 50:50, 응답 90:30은 75:25, 순서를 뒤집으면 25:75, 접선 방향 변화만 있으면 50:50 확인. 실제 앵커 준비 경로에서 필터 수렴 0.74996 및 양쪽 공통 목표 차이 0px, 강체 상태 유지와 정리 시 분담 캐시 제거 확인. 스크립트/셰이더 오류 없음.

- 흰 광택은 표면 노멀 셰이더 대신 `small_sprite_gloss.svg` 스프라이트 하나로 표현한다. 실제 공 그림의 알파 외곽에서 안쪽 부착점을 정하고 6점 보간으로 위치만 따라간다. 스프라이트 자체는 메시 와핑에서 제외해 타원 비율·크기를 고정한다. 원 반경 대비 폭 30%, 화면상 텍스처 폭 최소 12px, 각도 -42°, 불투명도 100%. 외곽 부착점은 텍스처별로 캐시한다. 62번 렌더 설정의 주/보조 셰이더 광택은 0이며 주변 색 반사는 유지한다. 얼음 상태에서는 숨기고 정리 시 제거한다.

- 스프라이트 광택 MCP 검사: 15개 공에 15개 부착, 광택 메시 프록시 0개, 몸체 좌표 기준 광택 종횡비 변화 0 확인. 11종 모두 부착·얼음 숨김/복구·상향 발사·정리 확인, 스크립트/셰이더 오류 없음.

- 광택 가시성 보정: 작은 공에서 1px 미만이던 흰 타원 두께를 키우고 캐릭터 선과 겹치던 부착점을 공 표면 쪽으로 이동했다. MCP 15개 공의 원본/확대 캡처에서 확인했고 해당 실행 로그에 스크립트·셰이더 오류는 없었다.
