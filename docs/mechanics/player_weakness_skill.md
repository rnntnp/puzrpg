# 플레이어 약화 스킬

상태: `NEEDS_PLAYTEST`

## 동작 계약

- 플레이어가 소유한 정상 합성마다 결과 공의 `merge_score`만큼 게이지를 즉시 얻는다. 콤보 배율, 실제 HP 피해, 포식 내구도, 피해 증감은 획득량에 영향을 주지 않는다.
- 적 소유 외부 합성, 오버플로우, 기믹 제거와 비합성 피해는 게이지를 주지 않는다.
- 게이지는 최대값에서 고정되고 같은 스테이지의 적 전환 동안 유지되며, 스테이지 시작과 종료에는 0이다.
- 최대 게이지이고 살아 있는 현재 적이 있으며 다음 드롭을 받을 수 있는 전투 상태일 때만 버튼을 사용할 수 있다.
- 사용하면 포식 저지 성공과 동일한 약화를 현재 적에게 2턴 추가하고 게이지를 0으로 만든다. 남은 약화가 1턴이면 사용 후 3턴이다.
- 포식 저지와 플레이어 스킬은 하나의 약화 턴 수와 상태 아이콘을 공유한다. 두 효과 모두 발생하면 남은 턴을 더한다.
- 약화는 플레이어 합성 투사체가 기존 내구도·기믹 경로를 지난 뒤 실제 적 HP에 줄 피해를 ×1.3으로 증가시킨다. 게이지 획득량은 변하지 않는다.
- 약화 턴은 완료된 플레이어 턴마다 1 감소한다. 적이 죽으면 제거되며 다음 적에게 이전되지 않는다.

## 초기값과 표시

- `resources/skills/player_weakness.tres`: 최대 게이지 300, 기존 약화에 +2턴.
- `resources/effects/ingestion_vulnerable.tres`: 포식 저지와 플레이어 스킬이 공유하는 받는 피해 배율 ×1.3.
- 캐릭터 머리 위 아이콘은 흑백 상태 위로 원본 색이 아래부터 차오른다. 최대일 때 아이콘 모양의 노란 외곽선이 여러 겹 바깥으로 퍼진다.
- 스킬 사용 시 플레이어에게서 투사체가 날아가지 않는다. 효과 적용 순간 현재 적 캐릭터 중앙에서 노란 충격파와 파편이 부서지듯 바깥으로 튄다.
- 현재 적의 상태효과 바에 약화 아이콘과 남은 턴을 표시한다.

## 플레이테스트 확인

- 연쇄 합성 각각의 `merge_score`만 더해지고 콤보 배율은 더해지지 않는가?
- 포식 약화와 스킬 약화가 한 아이콘에서 정확히 합산되는가?
- 버튼 위치, 아래→위 충전, 사용 가능 오오라가 즉시 이해되는가?
