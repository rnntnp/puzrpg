# 복원 파츠 v2

- 분홍 장식 9개와 장식 아래 꼬리를 완성된 형태로 분리했습니다.
- 각 복원 파츠는 Color - completed hidden surface / Line art - continuous contour 두 레이어입니다. 이전의 절단선 조각을 그대로 덮지 않고, 외곽선을 연속되게 다시 정리했습니다.
- 원본 PSD는 Original source - hidden 그룹에 보관했습니다. Dropbox 원본과 이전 전달 파일은 수정하지 않았습니다.
- PNG는 원본과 같은 1086×1448 투명 캔버스입니다. parts_manifest.json의 좌표와 표시 순서를 사용하면 같은 위치에 놓을 수 있습니다.
- motion_v2.gif: 실제 파츠를 약 ±8도 움직인 조립 상태 점검입니다.
- exposed_motion_v2.gif: 몸체나 이웃 파츠에 가려지지 않도록 모든 복원 파츠를 펼친 ±12도 점검입니다. 이 파일에서 복원된 전체 외곽선을 확인할 수 있습니다.
- 두 GIF는 완성된 게임용 idle 리깅이 아닙니다.
- 저장한 PSD를 다시 읽어 PNG로 내보낸 뒤 개별 PNG 재합성과 비교했습니다. validation.json에 결과를 기록했습니다. Procreate에서 직접 열어 본 검증은 아닙니다.
- 숨은 부분은 추정한 형태입니다. 접합부 채색과 외곽선을 보정했으므로 원본과 픽셀 단위로 같지는 않습니다.

이번 수정은 기존 PSD 파츠의 채색 및 선화 정리입니다. 앞선 내장 imagegen 복원 채색을 바탕으로 작업했으며, 새로운 전체 캐릭터를 생성하지 않았습니다.
